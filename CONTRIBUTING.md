# Contributing

Thanks for improving Universal AI Video Editor.

1. Open an issue describing the bug, integration, or feature.
2. Fork the repository and create a focused branch.
3. Keep changes small and add a test for changed behavior when practical.
4. Run `python -m unittest discover -s tests -v`.
5. Submit a pull request with a concise explanation and test results.

Do not commit copyrighted media, API credentials, private user videos, or personal data.
Tool integrations must accurately report unavailable capabilities rather than simulate success.
